## Remaining genuine blockers

1. **A4 rollback is resolved.** The earlier failure was caused by the prior procedure copying only a database file into the already-upgraded volume. The old file therefore coexisted with the upgraded database/WAL state, and the old image reconciled the upgraded schema rather than the intended pre-upgrade backup. The verified procedure stops all writers, archives the complete backend data volume with a checksum, restores it into a new empty volume, inspects the old schema before startup, and then starts v1.11.4 normally. The supported commands are documented in `docs/public/upgrading.md` under **Rolling back from 1.12.0 to 1.11.4**.
2. **Live listener-dependent rows remain unverified.** B2–B5, C1–C4 (unless independently evidenced), D1–D5, E1–E4, F1 and J2 require real TeamSpeak participants, a playable track and private HTTPS remote access. **A2 candidate fresh install and A3 request-history persistence** also remain incomplete. Reuse owner PASS for C5/C6 and F2–F7; do not rerun those unless relevant behaviour changes.
